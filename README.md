# Messoyakha OS

[Tactical asset allocation](https://en.wikipedia.org/wiki/Tactical_asset_allocation).

## ...

### What Is It?

A personal fintech environment for backtesting different trading strategies, building diversified portfolios and managing risk better in order to make optimal decisions in a face of uncertainty.

### What Is It For?

PEP offers a modular architecture in which each component plays a crucial role in building complex financial modeling and providing necessary tools for thorough analysis.

### Why Is It?

Simpler is generally better for retail market participants due to lack of time, data and capabilities in comparison to financial institutions such as banks, hedge funds and trading firms.

#### Installing `pre-commit` Hooks

This can be done by running:
```bash
uv run pre-commit install --install-hooks
```
Now all of the styling checks will be run each time you commit changes.

```bash
uv run pytest -s somewhere-in-messoyakha/tests/unit/test_dummy.py
```
